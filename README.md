# ラブライブ！フェス 座席ファインダー

「LoveLive! Series 15th Anniversary ラブライブ！フェス」（2026年11月14日・15日、バンテリンドーム ナゴヤ）の**スタンド席**の位置を、チケットの表記から図で確かめられる非公式ツールです。

## できること

- 1塁側／3塁側／アリーナを選びます。アリーナではアップグレードS／A／なしを選ぶと、その区画を図でハイライトします。スタンドでは列、番号（任意で通路・ゲート）を入力すると、ドーム図の上にピンで席の位置を表示します。チケットの表記（例：`２ゲート　スタンド３塁側　３８通路　L20列　300番`）を貼り付けて読み取ることもできます。
- ステージまでの距離の目安、ステージに対する向き（正面／斜め前／真横など）、双眼鏡の倍率の目安を出します。
- ステージ配置（センター側のメインステージ、花道、センターステージ、アリーナのS・Aエリア）は公式のSTAGE MAP（イメージ図）をもとに描いています。
- 公式のマップに描かれていないステージ横〜後ろのスタンドの席には、注釈付き指定席・見切れ席の可能性があると表示します。
- 座席の画像（ドーム図つき）と投稿文を作って、Xに共有できます。スマホでは共有画面でXを選ぶと、画像つきの投稿画面が開きます。パソコンでは画像を保存してXの投稿画面を開きます。ゲート・通路・列・番号は、それぞれ隠せます。列か番号を隠すと、図のピンの代わりに「だいたいこの辺」の丸で表示します。画像は端末の中で作るので、席の情報がほかのサーバーに送られることはありません。
- 調べた席の履歴は、その端末のブラウザにだけ残ります。

## できないこと

- アリーナ席の細かい位置：ブロックや列の並びは公演ごとに決まるので、アリーナは「アップグレードS／A／なし」の区画だけを表示します。
- 4階席。
- 正確な座席位置の保証：位置・通路・距離は、公開されている表記のルールと実際のチケット例から推定した目安です。ステージ配置もイメージ図をもとにしているので、実際の寸法とは異なります。

## 公開（GitHub Pages）

`index.html` 1ファイルだけで動きます。リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main`・`/ (root)` にして保存すると公開されます。
